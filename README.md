# 💕 A Journey Through Us - Romantic Pixel Art Adventure Game 💕

A cute, personal, and romantic 2D pixel-art adventure game created as a way to ask someone special to be your girlfriend!

## 🎮 How to Play

1. **Open the game**: Simply open `index.html` in any modern web browser, or access it at `http://localhost:8080` if running a local server.

2. **Controls**:
   - **Arrow Keys** or **WASD**: Move the character
   - **SPACE**: Interact with NPCs and objects

3. **Gameplay**:
   - Collect memory hearts throughout each level
   - Talk to NPCs to learn more about your story
   - Defeat the "Overthinking Monster" boss
   - Reach the final character and pop the question!

## 🌟 Game Features

- **5 Unique Levels**:
  1. **How We Met** - Relive the first meeting
  2. **Funny Moments** - Share laughs and inside jokes
  3. **Things I Love** - Express what makes her special
  4. **The Overthinking Zone** - Face the fears (boss battle!)
  5. **Reaching You** - The emotional finale

- **Collectible Memories**: Gather hearts that trigger dialogue scenes about your relationship

- **Interactive NPCs**: Characters that share meaningful messages

- **Boss Battle**: Conquer the "Overthinking Monster" with encouraging messages

- **Romantic Finale**: 
  - Emotional dialogue leading to the big question
  - "Will you be my girlfriend?" with an uncatchable NO button 😉
  - Celebration screen with hearts and confetti
  - "Achievement Unlocked: You + Me ❤️"

## 🎨 Customization

Make this game truly yours by editing `game.js`:

### Edit Memory Dialogues
Find the `levels` array and customize:
```javascript
memories: [
    { 
        x: 300, 
        y: 250, 
        title: "Your Custom Title", 
        text: "Your personal message here..." 
    }
]
```

### Change Colors
Edit the CSS in `styles.css` to match her favorite colors or your theme.

### Add Your Own Story
Modify the dialogue texts in:
- Memory collection messages
- NPC conversations
- Boss encounter lines
- Final scene dialogue

## 🚀 Running the Game

### Option 1: Direct Browser
Simply double-click `index.html` to open it in your default browser.

### Option 2: Local Server
```bash
# Python 3
python3 -m http.server 8080

# Then visit: http://localhost:8080
```

### Option 3: Deploy Online
Upload to GitHub Pages, Netlify, or Vercel for easy sharing!
